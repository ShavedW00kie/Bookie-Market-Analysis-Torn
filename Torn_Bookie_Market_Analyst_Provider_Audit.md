## Exact requests in this build

All external operations are GET-only; no Torn request is made.

- The Odds API: `https://api.the-odds-api.com/v4/sports`; `/v4/sports/{sport}/events`; `/v4/sports/{sport}/events/{eventId}/odds` with `apiKey`, `markets=h2h`, `regions=us`, `oddsFormat=decimal`.
- OddsPapi: `https://api.oddspapi.io/v4/account`, `/v4/fixtures`, `/v4/markets`, `/v4/odds`; `apiKey` authentication. Tournament filtering and fixture IDs are documented inputs. See [account](https://oddspapi.io/us/docs/get-account), [fixtures](https://oddspapi.io/us/docs/get-fixtures), [markets](https://oddspapi.io/us/docs/get-markets), [odds](https://oddspapi.io/us/docs/get-odds).
- Polymarket: `https://gamma-api.polymarket.com/markets/{numericMarketId}` and `https://clob.polymarket.com/book?token_id={outcomeTokenId}`, once per outcome. No authentication.

The adapter source is the exact authority for implemented parameters. No API key has been used in testing. All response fixtures are synthetic.

## Torn evidence and conflicts

The two supplied Torn documents were read before implementation. Neither supplies a Bookie event/odds selection. [Official Torn API documentation](https://www.torn.com/api.html) describes read-only access and treats keys as confidential, including Public-access keys. A Public key is a permission level, not an anonymous identifier. It does not establish Bookie availability. No key format or Torn request is imposed on external providers.

[Official Bookie wiki](https://wiki.torn.com/wiki/Bookie) describes accepted odds, regulation-time football settlement and refund scenarios. These do not prove current markup, displayed odds conventions or rounding. No conflict in an implemented Torn endpoint exists because none is implemented. The signed-out Bookie page was inspected; authenticated event markup was unavailable. The user's supplied public key was not used or copied into artifacts: it cannot replace missing page evidence.
